## Flappy Bird Game

A simple Flappy Bird clone written in Java using the Swing framework.

### How to Run

```bash
git clone https://github.com/ahmetyazlyyev5/FlappyBird.git
cd FlappyBird
javac -d bin src/*.java
java -cp bin App
```

### Controls

* **Spacebar** — flap / restart
* **B** — toggle bird hitbox
